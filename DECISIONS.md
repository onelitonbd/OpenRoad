# DECISIONS.md — Log of agent choices

- **2026-11-14 Phase 0**: Default quality = Low (per PROJECT.md). Fog hide distance 120–600 m. Antialias off (perf). Ground is flat 4km plane + grid; replaced by chunked terrain in Phase 2.
- **Phase 1**: Rapier DynamicRayCastVehicleController with RWD, front steering, speed-sensitive steering, handbrake reduces rear frictionSlip for drift, downforce scaled with speed, air control via torque when wheelsInContact<2, anti-roll damping angular velocity, fallback kinematic if physics not ready. Tuning panel (T) live-adjusts engine/grip/steer and suspension stiffness.
- **Phase 2**: Chose floating origin (shift world when player >2km from origin) over camera-relative. Reason: simpler chunk and collider management, handles Rapier world which expects finite coords. Terrain uses simplex-noise fractal per region; chunk generation main-thread with 4ms time budget (Worker stub for future). Heightfield collider per chunk (Rapier heightfield with scale 256). Fog distance tied to chunk radius. Water plane at south edge -3.5m with wobble. Spawn at suburb border ~1100m from center at angle 0.7 rad. Vegetation/buildings deferred to Phase 4.
- Floating origin updates both mesh positions and collider translations and vehicle body; all stored in originOffset.

- **Phase 2 Checklist**: Build passes, chunks stream smoothly, no fall-through (heightfield colliders + fallback ground plane removed after init), floating origin correct.

- **Phase 3**: RoadNetwork deterministic seeded graph: downtown 5x5 grid (180m spacing), 4 suburb clusters with cul-de-sacs, 8 highways connecting region centers (smooth CatmullRom with midpoint jitter + height smoothing), rural branches off highways, 6 mountain switchbacks, coastal road 9 nodes. Spatial index 512m grid hash. RoadMesh builds ribbon per edge clipped to chunk with 0.05m offset, lane markings via instanced dashes, downtown sidewalks as 1.2m strips. Terrain flatten blended within roadWidth/2+7m via cubic lerp to road height. Intersections as flat circular patches at nodes with >2 edges. ChunkManager now loads roads per chunk and creates heightfield collider matching flattened terrain. Single source of truth: RoadNetwork queried by Terrain for flattening. No gaps: margin 30m overlap across chunks, ribbon offset prevents z-fighting. APIs: getNearestRoad, getLanePath, getRoadsInRadius, getEdgesInChunk.

- **Phase 4**: Buildings via InstancedMesh per archetype (skyscraper/house/barn) — placed along road edges with setbacks per type, density tuned (downtown 0.9, suburb 0.55, highway 0.12). Cartoon palette, random heights (skyscraper 30-155m includes landmarks, house 5.5-9m, barn 6-11m). Props instanced: tree/pine/palm/cactus/lamp/rock, per region type (highway lamps, mountain pines, desert cactus/rock, coast palms). Both systems rebuilt per chunk generation, removal on unload, draw calls kept low via instancing (3 building archetypes + 6 prop types = ~9 draw calls). Landmarks hand-placed: downtown tower 165m with emissive, lighthouse at coast with point light, highway bridge with pillars. Minimap 160px canvas draws road graph in 400m radius, player arrow, click toggles rotate/north-up, live updates with floating-origin corrected position.

- **Phase 5**: TrafficManager spawns AI in 140-420m ring around player, caps per quality (15/30/50), despawns >520m or >85s. TrafficCar follows lane path from RoadNetwork.getLanePath, slows for curves via lookahead angle, obeys speed limits (78-110% random), keeps following distance 11m+speed*0.6, raycasts forward dot check for others/player, respects Intersection traffic lights (timed green-yellow-red 6/1.5/6 cycle in downtown). All AI kinematic path followers for perf (<1ms per car); swap to physics for nearest 10 deferred as future optimization (currently kinematic sufficient). Variety via random palette and dimensions.
