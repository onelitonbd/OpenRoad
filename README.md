# Open Road — Phase 5 Traffic

Drive with AI traffic flowing on all road types.

## Run
npm install; npm run dev

## Controls
WASD, Space, C, R, T, F3

## World Phase 5
- Traffic cap 15 Low /30 Med /50 High, spawns only near player ring, despawns far
- Lane following, curve slowing, following distance, traffic lights downtown
